# Chrome Web Store listing (copy and paste)

## Name
Markdown Folder Viewer

## Summary (max 132 characters)
Read Markdown files and whole folders of docs with working links, search, diagrams and PDF export. Nothing is uploaded.

## Category
Tools (or Developer Tools)

## Description
Open a folder of Markdown docs and read it like a website.

Plans, specs, requirements, notes, project docs: more and more of our work lives in .md files. This extension shows
them the way GitHub does, and lets you move around a whole folder easily.

WHAT YOU CAN OPEN
• A single .md file, several files, or a whole folder: pick it or drag it in
• Any folder layout: nested folders, README or index files, docs sites, Obsidian vaults
• .md files you open in Chrome from your computer show formatted too (turn on "Allow access to file URLs" in the
  extension's details)

WHAT YOU GET
• A folder tree, breadcrumbs, previous / next, and an "On this page" list
• Links between files that work, including ../ paths, #headings and [[wiki links]]
• Search across every file, with matches highlighted
• Tables, task lists, code highlighting, callouts, images and Mermaid diagrams
• Save as PDF: one page, or the whole folder as one PDF with a contents page
• Dark mode

PRIVATE BY DESIGN
Your files are read inside your browser and never leave your computer. No accounts, no tracking, no network requests.

## Single purpose (Privacy tab)
Shows Markdown (.md) files and folders of Markdown files as formatted, linked pages.

## Permission justification (Privacy tab)
Host permission / content script on file:///*.md: so that a .md file the user opens in Chrome from their own computer
is shown formatted instead of as plain text. It runs only on files ending in .md, .markdown, .mdown, .mkd, .mkdn or
.mdx, and only if the user turns on "Allow access to file URLs".

## Remote code
No, I am not using remote code. All JavaScript is included in the package.

## Data usage
Tick nothing. The extension does not collect or use any user data.
Tick the three certification boxes (no selling data, no unrelated use, no creditworthiness use).
