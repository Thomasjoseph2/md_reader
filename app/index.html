How a review works

  1. Share the folderSend your docs the way you already share files. Reviewers open them here, with no account.
  2. Comment in the marginSelect any sentence to comment, ask a question or suggest new wording. Or comment on a whole file or folder.
  3. Get one file backEach reviewer downloads a review file. Open them together and every comment shows in place, with who said it.

Open and read Markdown files online

Markdown (.md) files are plain text. In a text editor or a browser tab they show raw symbols like #, ** and |. This free viewer shows them properly, and lets you move around a whole folder of them like a small website.

  • Files or whole foldersOne file, several files, or a folder with sub-folders. README and index files open first.
  • Links that workLinks between files, ../ paths, #headings and Obsidian [[wiki links]].
  • Search everythingSearch across every file at once, with matches highlighted on the page.
  • Diagrams and codeTables, task lists, callouts, images, code highlighting and Mermaid diagrams.
  • Markdown to PDFSave one page, or the whole folder as one PDF with a contents page.
  • Private by designFiles are read in your browser. Nothing is uploaded, and there is no account.

How to open an .md file

  1. Drag the .md file (or a folder) onto this page. Or click Open files or Open a folder.
  2. It shows formatted at once. Pick other files from the list on the left.
  3. Click PDF to save it as a PDF, Comments to review it, or press / to search.

Questions

What is an .md file?

A Markdown file: plain text with simple marks for headings, lists, links and tables. README files, notes apps like Obsidian, and many project plans and docs use it.

Are my files uploaded?

No. Your browser reads them on your own computer. Nothing is sent anywhere, so it is safe for private documents.

How do review comments work?

Select text and click Comment. When you are done, click Download review and send that one file back. The owner opens it with Open review files and sees every comment in place.

Which Markdown does it support?

GitHub-style Markdown: tables, task lists, fenced code with highlighting, > [!NOTE] callouts, front matter, images, Mermaid diagrams and [[wiki links]]. Also .markdown, .mdx and .txt files.

Can I convert Markdown to PDF?

Yes. Click PDF, then choose “Save as PDF” in the print window. Links between documents still work inside the PDF.

Does it work on a phone?

Yes. Tap Open files to pick .md files. Opening whole folders works best on a computer.

Is there a Chrome extension?

Yes. The extension also shows .md files you open in Chrome straight from your computer. The source is on GitHub.
